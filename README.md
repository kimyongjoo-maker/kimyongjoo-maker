### 🚀 About Me
- **대용량 데이터 및 배치 처리 전문가:** 공공 부문 대형 포털 및 행정 시스템에서 일일 수십만 건의 정산·통계 데이터를 처리하는 **Spring Batch 파이프라인**을 설계하고 최적화했습니다.
- **데이터베이스 중심의 트러블슈팅:** 단순 ORM 사용에 그치지 않고, **실행 계획(Explain Plan) 분석, 복합 인덱스 재설계, 윈도우 함수 쿼리 튜닝**으로 슬로우 쿼리와 병목 현상을 해결합니다.
- **안정적인 레거시 모더나이제이션:** 노후화된 시스템을 **Spring Boot 기반 RESTful API 아키텍처**로 전환하여 유지보수성과 시스템 가용성을 극대화한 경험이 있습니다.
